# 🎭 Emotion-Aware AI Story Generator

## 📌 Overview
This project is an AI-based application that generates stories and images based on the user's emotion.  
It takes a text input, detects the emotion, creates a story, and generates a related image.

---

## 🚀 Features
- Detects emotion from text input  
- Generates emotion-based story  
- Creates image using AI  
- Simple and interactive UI  
- Uses free and open-source models  

---

## 🧠 Technologies Used
- Python  
- Streamlit  
- Transformers (Hugging Face)  
- PyTorch  
- Diffusers (Stable Diffusion)  
- PIL  
- Ngrok  

---

## ⚙️ How It Works
1. User enters text  
2. Emotion is detected  
3. Story is generated based on emotion  
4. Image is generated from text  
5. Results are displayed in UI
